# Aniwalk - 聖地巡禮資訊分享平台
![img1](README/img1.jpg)

## 發想與製作動機
目前喜歡動漫畫已經是個非常普遍的興趣，很多人不僅喜歡觀賞動畫，更會親自前往每部動畫中實際繪製的地點進行朝聖，即所謂的「聖地巡禮」，並用相機記錄當下的感動，撰寫文章發布於網路上與同好分享。然而目前市場上缺乏一個能夠系統性整理聖地巡禮記錄的平台。絕大多數的動畫愛好者多仰賴傳統部落格、社群平台等工具來發布遊記，這些平台雖然普及，但缺乏針對動畫聖地巡禮所需的特殊功能，諸如景點與動畫場景對照、動畫作品分類等，使得資訊分散、檢索困難，也難以與其他同好交流或參考。

為了滿足動畫愛好者分享自己聖地巡禮的經歷，決定開發一個新的「聖地巡禮資訊分享平台」：一個結合地圖資訊、影像整理、貼文、動畫標記、與社群互動功能的整合性網站。使用者可透過地圖檢索或清單檢視快速瀏覽每個用戶所發布的聖地巡禮記錄；亦可自行上傳旅行中拍攝的照片，並加入使用者自己的到訪經歷，與全世界的動畫愛好者分享。

此外，該平台也提供社群互動機制，用戶可在其他人的到訪紀錄下留下評論與回覆，進一步建立起以動畫旅遊為核心的社群圈。透過這樣的系統，讓全世界的動畫愛好者可以更有系統地紀錄、分享並保存自己的聖地巡禮回憶，平台也能持續透過數據分析與用戶回饋進化，成為動漫與旅遊結合的創新應用服務。

---

## 簡介

* **用途**：專為動漫愛好者設計的聖地巡禮分享與交流平台
* **價值**：系統化整理聖地巡禮資訊，解決目前資訊分散、難以檢索的問題，提升愛好者的分享與交流體驗。對於想進行聖地巡禮的人也能提供更便捷的規劃參考。
* **目的性**：建立一個以動畫旅遊為核心的社群圈，促進全球動畫愛好者的交流，並作為聖地巡禮回憶的系統性保存庫。

## 功能描述

### 1. 到訪紀錄
1. 新增聖地巡禮到訪紀錄
   - 填入到訪紀錄的主文內容
   - 填寫到訪日期、所在國家、對應動畫等相關資訊
   - 在地圖上點選地理座標（經緯度）
   - 上傳多張現場照片並填寫照片說明
2. 編輯與刪除自己的到訪紀錄

### 2. 評論與回覆
1. 在其他會員的到訪紀錄下撰寫評論
2. 在評論下留下回覆
3. 修改自己的評論或回覆
4. 刪除自己的評論或回覆

### 3. 到訪紀錄瀏覽與檢索
1. **地圖檢視**：在 Google Maps 上瀏覽所有到訪紀錄，點擊地圖標記可彈出簡易紀錄詳情
2. **清單檢視**：以分頁清單方式瀏覽到訪紀錄
3. 輸入篩選條件（動畫、國家、日期等）縮小搜尋範圍

### 4. 會員功能
1. 註冊新帳號
2. 登入 / 登出
3. 瀏覽與修改個人資料
4. 忘記密碼流程（Email 驗證信箱後重設密碼）
5. 填寫新增動畫建議：新增到訪紀錄時若無對應動畫分類，可送出建議單請管理員新增

### 5. 管理者功能（後台）
1. 審核、核准或否決會員新增的動畫建議
2. 新增與管理動畫分類
3. 發布與編輯站內公告
4. 檢視與管理會員資訊及會員狀態（正常 / 封鎖 / 註銷）
5. 檢視與管理所有到訪紀錄
6. 檢視與刪除評論及回覆
